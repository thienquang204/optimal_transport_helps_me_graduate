GreenkhornMMPOT

Multi‑Marginal Partial Optimal Transport via Sinkhorn Rescaling

A differentiable, Sinkhorn‑style algorithm for Entropic Multi‑Marginal Partial Optimal Transport (MMPOT). Designed for deep learning pipelines where the cost tensor is parameterized by a neural network.

Why MMPOT?

Traditional Optimal Transport (OT) enforces exact mass conservation – all mass must be transported. Partial OT (POT) relaxes this constraint: only a fraction s of the total mass is moved, the rest is discarded. Multi‑Marginal POT (MMPOT) handles m ≥ 2 distributions simultaneously.

Previous approaches reduce MMPOT to standard OT by adding dummy points. This trick:
  • Produces infeasible solutions under entropy regularization,
  • Worsens the computational complexity to 𝒪(ε⁻⁴),
  • Lacks a clean, differentiable structure.

Our approach uses a primal‑dual formulation with explicit slack variables, leading to a pure multiplicative rescaling scheme – exactly the same flavour as Sinkhorn – that is:

  • Feasible at every iteration (one constraint is exactly satisfied after each step),
  • Fully differentiable (all operations are elementary),
  • Faster: 𝒪(ε⁻²) iteration complexity.

Mathematical Setup

Primal Problem (with Slacks)

Let p₁, …, pₘ ∈ Δn be discrete probability measures, s ∈ (0,1] the total mass to transport, and C ∈ ℝn × … × n an m-way cost tensor.

We seek a tensor X ≥ 0 and slack vectors qk ≥ 0 such that:

rk(X) + qk = pk   ∀ k,    ⟨X, 1⟩ = s

where rk(X) is the k-th marginal of X. The objective is:

minX,q ⟨C, X⟩ + η ∑ Xi log Xi + η ∑k,j qk,j log qk,j

(the entropy term guarantees strong convexity and smoothness).

Dual Problem

Introduce dual variables uk ∈ ℝn (for each marginal) and t ∈ ℝ (for the total mass). After simplifying, we obtain the smooth unconstrained dual:

minu₁,…,uₘ,t φ(u,t) = D log( ∑ exp( t + ∑ uk,ik − (1/η) C ) + ∑ ||exp(uk)||₁ ) − ∑ ⟨uk, pk⟩ − ⟨t, s⟩

where D = s + m(1−s).

The Rescaling Trick (Core Insight)

Instead of doing coordinate descent in the log‑space, we exponentiate the dual variables and obtain multiplicative updates – exactly like classical Sinkhorn.

Define the scaling vectors:

vk = exp(uk) ∈ ℝn+,    w = exp(t) ∈ ℝ+

and the Gibbs kernel:

Ki₁,…,iₘ = exp( − Ci₁,…,iₘ / η )

Then the primal variables can be recovered without ever forming the full nm tensor:

Xi₁,…,iₘ = (D / S) · w · Ki₁,…,iₘ ∏ vk,ik
qk,j = (D / S) · vk,j

where the partition function is:

S(v,w) = w · ∑ K · ∏ vk + ∑ ||vk||₁

From these, the current marginal estimate Rk and total mass M are:

Rk,j = (D / S) · ( w · [rk(K ⊙ v₁ ⊗ … ⊗ vₘ)]j + vk,j )
M = (D / S) · w · ∑ K · ∏ vk

GreenkhornMMPOT Algorithm

At each iteration, we identify the constraint with the largest violation (using the Bregman divergence ρ(a,b) = 1ᵀ(b−a) + ∑ ai log(ai/bi)). Then we apply a pure rescaling step:

Pseudo‑code

Inputs:
  C            : m‑way cost tensor (or callable function)
  p₁...pₘ     : marginals (each of size n)
  s            : total mass to transport (0 < s ≤ 1)
  η            : entropy regularization strength
  ε            : tolerance for constraint error
  T_max        : maximum iterations

Initialize:
  v_k = 1ₙ  for all k
  w = 1
  K = exp(-C / η)            // can be implicit

for τ = 1 to T_max:

    // ---- compute scaled kernel and partition ----
    B = K ⊙ (v₁ ⊗ v₂ ⊗ ... ⊗ vₘ)
    S = w * sum(B) + sum_k sum(v_k)

    // ---- compute current estimates ----
    for k = 1..m:
        R_k = (D / S) * ( w * r_k(B) + v_k )
    M = (D / S) * w * sum(B)

    // ---- compute errors ----
    err_k   = ρ(p_k, R_k)       for all k
    err_mass = ρ(s, M)

    // ---- greedy selection and rescaling ----
    if max_k err_k > err_mass:
        I = argmax_k err_k
        v_I = v_I .* (p_I ./ R_I)       // element‑wise
    else:
        w = w * (s / M)

    // ---- check convergence ----
    E = sum_k ||R_k - p_k||₁ + |M - s|
    if E < ε:
        break

Output: v₁...vₘ, w  (implicitly define X and qₖ)

Why This Works (Intuition)

  • Marginal update: RI is linear in vI. Multiplying vI by pI / RI sets RInew = pI exactly.
  • Mass update: X is linear in w. Rescaling w by s/M sets Mnew = s exactly.
  • The algorithm greedily corrects the worst violated constraint, guaranteeing a decrease of the dual objective proportional to Eτ² (see below).

Convergence Guarantees (Theoretical Bounds)

Quantity Bound
Dual gap φτ − φ* ≤ (m+1)·ℛ · Eτ
One‑step progress φτ − φτ+1 ≥ ½ ( Eτ / (m+1) )²
Iterations to reach Eτ ≤ ε τ ≤ 2 + 2√2 · (m+1)³·ℛ / ε
Total complexity 𝒪̃( m⁴ nm ||C||∞ / ε² )

where ℛ = 𝒪( ||C||∞/η + log(max p / min p) ).

Remark: For structured costs (e.g., sum of pairwise distances), the complexity drops to 𝒪̃(m² n² / ε²).

Deep Learning Integration

Differentiability

Every operation in the loop (exp, log, +, *, /, sum) is elementary and differentiable. You can use:

  • Unrolled differentiation – backpropagate through a fixed number of iterations.
  • Implicit differentiation – treat the final optimality conditions as a fixed‑point and differentiate via the implicit function theorem (more memory efficient).

Handling Large Tensors

Storing the full nm tensor is impossible for large m or n.

  • If C is given by a neural network Ci₁,…,iₘ = fθ(zi₁, …, ziₘ), compute rk(B) on‑the‑fly by aggregating over dimensions.
  • For additive costs C = ∑a<b cia, ib, the kernel factorises, reducing complexity to O(m n²).

Usage in a Loss Function

# Forward pass
v, w = greenkhorn_mmpot(cost_fn=my_network(embeddings),
                        p=p_list, s=s, eta=eta, eps=1e-3)

# transport_cost = ⟨C, X⟩ = (D/S) * w * sum( B ⊙ C )
loss = transport_cost + lambda * task_loss(X)   # X is implicit
loss.backward()   # automatic differentiation

Numerical Stability Tips

  • Use logsumexp to compute S and the marginals – this avoids overflow.
  • Clip vk and w to [10⁻¹⁰, 10¹⁰] after each update.
  • Start with vk = 1, w = 1.
  • For warm‑start (e.g., in sequential batches), reuse the previous v,w.

Why Not the Dummy‑Point Trick?

Approach Feasibility Complexity Differentiability
Dummy‑point reduction Infeasible (entropy breaks constraints) 𝒪(ε⁻⁴) Poor (sparse updates)
